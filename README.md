# hvad-skal-vi-seerr

A small recommender that learns from your own Jellyfin watch history and
Jellyseerr/Overseerr requests, and tells you what to watch next from what's
already sitting in your library. Used to demonstrate a minimal train/serve
MLOps split: train on someone else's compute (Google Colab), ship only the
tiny artifact you need to the machine that serves recommendations.

## How it's split

```
   Your PC (export_history.py)      Colab (train.ipynb)             Your PC (recommend.py)
   ----------------------------     ----------------------------    ----------------------------
   pulls your Jellyfin library +    upload library.csv (manual,     loads weights + the same
   play history, and your           never committed), trains a     library.csv, scores every
   Jellyseerr request history       tiny logistic-regression        unwatched item, prints a
   -> writes library.csv            classifier on genre/year        ranked "watch next" list
      (gitignored)                  features vs. watched label
```

Training needs `torch`; serving needs neither `torch` nor any network access.
Keeping those dependency sets and code paths separate
(`requirements-train.txt` / `requirements-infer.txt` / `requirements-export.txt`)
is the actual MLOps lesson here - everything else is kept as small as possible.

## Model

A single linear classifier (genre one-hot + normalized release year ->
probability you'd watch it), trained on your own `watched OR requested OR
favorited` signal. This is content-based, not collaborative filtering - with
only one user's history there are no other users to collaborate with. A
linear model is enough to show the pipeline; it's not meant to be fancy.

## 1. Export your history (run locally, not in a cloud sandbox)

Needs network access to your Jellyfin / Jellyseerr instance (usually your
home network).

```
pip install -r requirements-export.txt

export JELLYFIN_URL=http://<your-server>:8096
export JELLYFIN_API_KEY=<from Jellyfin dashboard > API keys>
export JELLYFIN_USER_ID=<run with --list-users if you don't know it>

# optional - skip to export Jellyfin-only data
export JELLYSEERR_URL=http://<your-server>:5055
export JELLYSEERR_API_KEY=<from Jellyseerr/Overseerr settings>

python export_history.py --list-users   # find your JELLYFIN_USER_ID
python export_history.py                # writes library.csv
```

`library.csv` is your personal data - it's gitignored and should stay that way.

## 2. Train it

1. Open `train.ipynb` in Colab (badge at the top of the notebook, or
   `Open in Colab` from this repo's GitHub page).
2. `Runtime > Run all`, upload `library.csv` when prompted.
3. The last cell downloads `models.zip`.

## 3. Run it locally

```
unzip models.zip -d .          # puts the artifacts in ./models
pip install -r requirements-infer.txt
python recommend.py --library library.csv
```


## Files

- `export_history.py` - pulls your watch + request history into `library.csv` (run locally).
- `train.ipynb` - the only thing that needs to run on Colab.
- `recommend.py` - local inference, numpy/pandas only, no network calls.
- `requirements-export.txt` / `requirements-train.txt` / `requirements-infer.txt` - deliberately separate.
- `models/` - where trained artifacts land locally (gitignored, generated by the notebook).

## Possible extensions (not implemented, kept out on purpose)

- Recommending titles *not yet in your library* (would need a TMDB/trending feed and a Jellyseerr request step).
- Swapping the linear model for a small neural net if genre+year ever stops being good enough signal.
