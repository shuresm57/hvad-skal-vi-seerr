# hvad-skal-vi-seerr

A small movie recommender used to demonstrate a minimal train/serve MLOps split:
train on someone else's GPU/CPU (Google Colab), ship only the tiny artifact you
actually need to the machine that serves recommendations.

## How it's split

```
   Colab (train.ipynb)                    Your PC
   ---------------------                  -----------------------
   downloads MovieLens 100k        ->     models/*.npy, *.json, *.csv
   trains a matrix-factorization          (small artifacts, no torch
   model in PyTorch                       and no raw dataset needed)
   evaluates RMSE on a test split  ->     recommend.py
   writes metrics.json as a                reads the artifacts with
   record of what was trained              numpy + pandas only and
                                            prints top-N recommendations
```

The point: training needs `torch` and a GPU-friendly environment, serving
needs neither. Keeping those dependency sets (`requirements-train.txt` vs
`requirements-infer.txt`) and code paths separate is the whole MLOps lesson
here - everything else is intentionally as small as possible.

## Model

Plain matrix factorization with user/item bias terms, trained on
[MovieLens 100k](https://grouplens.org/datasets/movielens/100k/) (100,000
ratings, 943 users, 1,682 movies). Not state of the art - that's not the
point - but it's a real, evaluated model with a real artifact boundary.

## Train it

1. Open `train.ipynb` in Colab (badge at the top of the notebook, or
   `Open in Colab` from this repo's GitHub page).
2. `Runtime > Run all`. Takes well under a minute on CPU.
3. The last cell downloads `models.zip`.

## Run it locally

```
unzip models.zip -d .          # puts the artifacts in ./models
pip install -r requirements-infer.txt
python recommend.py --user_id 1
```

```
Top 10 recommendations for user 1:
 1. Some Movie (1994)  (predicted rating: 4.52)
 2. Another Movie (1996)  (predicted rating: 4.41)
 ...
```

User ids are MovieLens's original ids, roughly `1`-`943`.

## Files

- `train.ipynb` - the only thing that needs to run on Colab.
- `recommend.py` - local inference, numpy/pandas only.
- `requirements-train.txt` / `requirements-infer.txt` - deliberately separate.
- `models/` - where trained artifacts land locally (gitignored, generated by the notebook).
